# Blog examples

Runnable example code from the articles on [How It Ships](https://blog.masonships.app), a blog about building software.

Each article that comes with code has a folder here, named after the article's address on the blog. The folder's README explains what the code shows, what it was tested with and how to run it. The code is written to reproduce what an article describes, so it is kept small and is not meant to be used as a library.
